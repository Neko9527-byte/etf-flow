# ETF 细分行业资金流向 · 每日自动更新

这是 [etf-flow-d0j.pages.dev](https://etf-flow-d0j.pages.dev/) 数据的独立备份站。
每天由 GitHub Actions 自动抓取最新交易日数据、提交并重新部署，不需要服务器，也不需要电脑开机。

## 页面地址

部署成功后：

- `https://<你的用户名>.github.io/<仓库名>/`
- 如果仓库名是 `<你的用户名>.github.io`，地址就是 `https://<你的用户名>.github.io/`

## 自动更新

- 北京时间 **18:40、20:02、21:20、22:40**（周一至周五）各抓一次；
- 北京时间 **次日 08:30、10:30**（周二至周六）再兜底抓两次；
- 也可以在 **Actions → 更新数据并部署 → Run workflow** 手动触发。

抓取失败（比如原站暂时打不开）不会影响已部署的页面，只是当天不新增数据。
早一次抓到的如果是交易所的参考值，后面一次会用最终值覆盖同一天的数据。

## 目录

```
dist/                   网站文件（index.html + assets + data.js）
data/etf_flow.json      完整历史数据集
tools/                  抓取、合并、构建脚本
.github/workflows/      定时任务与部署配置
```

## 说明

- 数据来自沪深交易所公开接口，由原站作者“B站生炸瓜”整理，本仓库仅做备份与重新呈现，不构成投资建议。
- 页面代码为本项目自行实现。
